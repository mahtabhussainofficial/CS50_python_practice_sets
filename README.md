# CS50P Python Practice Sets

Practice solutions and learning exercises from [CS50's Introduction to Programming with Python (CS50P)](https://cs50.harvard.edu/python/).

This repository documents a progression through fundamental Python concepts, including variables, functions, conditionals, input handling, string manipulation, arithmetic, and formatted output.

## Getting Started

### Prerequisites

- Python 3.x
- A terminal or code editor

### Run an Exercise

Clone the repository, move into the project directory, and run any exercise with Python:

```bash
git clone https://github.com/mahtabhussainofficial/CS50_python_practice_sets.git
cd CS50_python_practice_sets
python3 conditionals/meal_time.py
```

Most programs prompt for input directly in the terminal. Replace the example path with any `.py` file you would like to explore.

## Learning Goals

- Build confidence with Python syntax and program structure
- Practice writing and calling functions
- Process user input and convert values between types
- Apply conditional logic to real-world-style problems
- Improve readability through clear organization and formatting
